# 运营实现迁移记录

状态：历史实验已核对；正式运营服务待实现。

历史 Rust 运营原型及网页服务位于 `codex/operation-simulator`（`72cc194d`，[历史 PR #13](https://github.com/Sakura-Ex/Hyacimicon/pull/13)）。替代网页界面的实验位于 `feat/player-web-simulator`（`2a4b3450`）。历史提交保留供后续检索。

## 取舍

正式开发使用同一套桌面界面、会话契约及 `run-core` 路线。旧网页、Python 运营实现及固定进度的 Rust 原型不纳入正式工作区。原型依赖历史节点列表，持有独立的整局状态与诊断数据；直接纳入会增加重复实现和未经验证的规则。

历史基础配置保存于[运营原型配置](../../game-data/operations-base-pack.json)，作为待核对资料。原型的商店、资源、阵容与投资操作可作为后续实现的参考；复用前先与统一数据结构、版本及实测证据核对。

## 接入验收条件

- 统一路线和状态归属，复用已有 `run-core` 路线及会话契约。
- 失败操作保持状态不变；位置越界、满容量、资源不足和重复动作返回明确错误。
- 资源数量保持有效，随机来源显式指定，同一输入和种子可复现。
- 用独立的公开合成样例检验状态不变量；私有数据与规则版本显式匹配。
- 模型只读取可见状态；诊断及隐藏信息保持独立。
- 正式结算通过战斗接口，训练和研究界面使用同一实现。
