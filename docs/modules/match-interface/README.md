# 对局接口

本文记录已核对的局面、操作和状态变化，供 Rust 接口设计与前端、模型接入使用。开局、备战和战斗交接按玩家描述整理。具体实测版本号和可复现样本待登记。

[会话接口设计](contract.md)说明入口、各阶段动作、控制权交接和战斗结算。用于客户端对照的[接口类型声明](../../../apps/src/match-session-contract.ts)覆盖请求、快照、动作、更新消息和战斗交接。

本分支记录对局接口及规则。会话执行、候选发放和战斗交接的接入方案见[会话接口设计](contract.md)。

## 开局到 1-1

| 时点 | 可见局面 | 操作与变化 |
| --- | --- | --- |
| 开始对局后 | 按位面列出竞争对手，包括怪物和首领。具体节点对应关系尚未揭示。负面词条已可见 | 进入投资环境选择 |
| 选择投资环境 | 三个候选，每个候选有一次刷新机会 | 刷新候选，或选定一个环境并进入 1-1 |
| 进入 1-1 | 商店 3 级、3 金币、一个白色晶矿、一个蓝色晶矿。初始角色为两名一费加两名二费，或三名一费加一名三费 | 开始常规备战 |

## 常规备战

玩家可以购买角色、刷新商店、调整站位和装备、开启晶矿。局面记录商店报价、角色与格位、库存与装备归属，以及当前可执行的动作。

| 操作 | 已确认行为 |
| --- | --- |
| 合成装备 | 可以在物品栏合成，也可以在角色身上合成。对已经穿戴简易装备的角色再使用简易装备，会和原有装备合成为对应装备 |
| 使用普通扳手 | 消耗一次使用机会，将目标角色身上的装备全部拆下 |
| 使用精密扳手 | 可反复使用，每次将目标角色身上的装备全部拆下 |
| 使用冶金炉 | 可指定一件装备或一个角色。对角色使用时，将其身上的装备全部随机并放回物品栏 |
| 开启晶矿 | 常规备战可开启。投资策略、补给或主角光环待选时，先从选择界面返回备战才能开启。备战席满 9 格时禁止开启。奖励内容事前未知，开启后直接发放 |

晶矿品质从低到高为白、蓝、金、彩。白色晶矿通常给 2 金币、最多 3 金币是玩家估计，完整战利品表和概率待核对。策略和界面可以读取已有晶矿的品质，开启后才能看到本次实际奖励。

部分羁绊在常规备战提供额外选择。有的确认一次后锁定。可以反复更改的选择在羁绊旁有入口，打开后可以直接确认当前选项，也可以换选后再确认。投资策略、补给和主角光环待选时，返回备战也不开放羁绊操作。

## 战斗交接与结算

| 时点 | 责任与动作 |
| --- | --- |
| 开始战斗 | 对局服务组装本场所需的全部单位信息并交给战斗模块，运营动作锁定 |
| 战斗中 | 战斗模块处理单位行动。行动值归零或敌方全部被击败时，战斗模块返回本场结果和进度 |
| 主动暂离 | 保留运营局面，回到备战界面后只能调整角色站位。重新进入时按当时站位从头开始战斗，使用新的战斗随机序列 |
| 战斗中直接重开 | 从头开始战斗，沿用本次进入时的战斗随机序列。相同顺序的操作得到相同结果 |
| 战斗结束 | 战斗模块返回本场最终结果后立即结算，随后回到运营阶段。重开只在战斗结束前可用。对局服务结算血量增减和本场收益 |

所有战斗都结算基础奖励、利息和火热连胜奖励。基础奖励记录为 5 金币。利息按开战前的金币计算，每 10 金币给 1 利息，常规上限为 5。普通战斗、遭遇和首领战胜利可增加火热连胜数，失败清零。先更新连胜数，再按更新后的数值结算连胜奖励。战斗随结算发放 2 经验，幕后茶歇属于例外。

### 战斗血量结算

设计采用四舍五入，待实测复核。进度未满时，按 `最低值 + (最高值 − 最低值) × (100 − 进度) / 100` 计算进度失血，再四舍五入。进度达到 100% 时进度失血为 0。

| 位面 | 0% 进度 | 99% 进度 | 100% 进度 |
| --- | ---: | ---: | ---: |
| 第一位面 | 15 | 5 | 0 |
| 第二位面 | 25 | 10 | 0 |
| 第三位面 | 35 | 15 | 0 |

遭遇进度低于 25% 或首领进度低于 33% 时，已取整的进度失血翻倍。刚好达到门槛时结算原值。

先扣除本场失血，再应用每关固定回复的 2 点和其他血量变化。最终血量取 `min(血量上限, 加减后的血量)`，最终血量小于或等于 0 时判定整局失败。

奖励关的怪物会掉落晶矿。战斗和遭遇节点可能出现扑满，击杀时会掉落晶矿，品质分布待核对。每只怪物掉落的晶矿品质和数量固定。直接重开或暂离后重新进入时，怪物会重新掉落晶矿；结算按最终打完的那次战斗收到的掉落更新可见库存。按玩家印象，1-1 有两只小怪，常见掉落两白两蓝；1-2 有三只小怪，常见掉落三白三蓝。这两组数量作为后续实测线索。

## 投资策略与特殊节点

完整路线有 23 个位置，其中 `1-5`、`2-3`、`3-3` 是补给节点。补给节点占路线位置，正常情况下不计入按节点触发的效果。数值快照列的是其余 20 个常规节点。

| 位面 | 路线顺序 |
| --- | --- |
| 第一位面 | `1-1` 奖励 → `1-2` 奖励 → `1-3` 战斗 → `1-4` 战斗 → `1-5` 补给 → `1-6` 战斗 → `1-7` 遭遇 → `1-8` 奖励 → `1-9` 首领 |
| 第二位面 | `2-1` 战斗 → `2-2` 战斗 → `2-3` 补给 → `2-4` 战斗 → `2-5` 遭遇 → `2-6` 奖励 → `2-7` 首领 |
| 第三位面 | `3-1` 战斗 → `3-2` 战斗 → `3-3` 补给 → `3-4` 战斗 → `3-5` 遭遇 → `3-6` 奖励 → `3-7` 首领 |

路线位置与节点触发计数分别记录。推进路线时保留补给位置，判断按节点触发的效果时使用对应规则，避免用路线下标直接计算触发次数。

| 事项 | 节点与触发条件 |
| --- | --- |
| 投资策略 | 1-3、2-2、3-2。上一场战斗先结算，再选策略，选完正式进入同编号的战斗节点 |
| 遭遇 | 1-7、2-5、3-5 |
| 幕后茶歇 | 由奇遇伙伴决定。触发时替代 1-8、2-6、3-6 中一个奖励关的战斗，每局最多替代一个 |
| 主角光环 | 第一、第二位面的首领战前，在首领备战中主动进入选择 |

### 补给节点

补给界面有五组角色和装备的组合，有一次刷新全部候选的机会。必须选取一组，领取后自动推进到下一节点。第一、第二位面的装备为简易装备，第三位面为进阶装备。补给还可能刷出红钻或蓝钻，第三位面还可能刷出财富宝钻和星辉。

待选时可以按按钮返回备战，备战操作只允许开启晶矿。回到补给选择时保留原候选和刷新次数。

### 投资策略

玩家需要从三个候选中选一项。每个候选格只有一次刷新机会，刷新后保持品质。三个候选默认随机到同一品质，投资环境「银·金·彩」会改变该品质安排。

上一场战斗结算后，金币和晶矿已经可见。此时界面显示即将进入的节点编号（如 `2-2`），阶段是投资策略待选。待选时可以按按钮返回备战，备战操作只允许开启晶矿。回到策略选择时保留原候选和刷新次数。

选定策略后才正式进入同编号的战斗节点，并处理进入节点时触发的收益，例如入节点发放的金币。上一场战斗的结算与本节点的进入结算发生在不同阶段。局面需要分别记录显示的节点编号和阶段，避免显示 `2-2` 时就提前发放入节点收益。

### 主角光环

进入第一或第二位面的首领节点后，先进行常规备战。打开光环选择后，可从两个候选中为一名角色选择一个光环。按按钮返回备战界面后仍处于光环待选阶段，可以调整角色格位，包括在备战席和场上之间互换。设计采用此时也可开启晶矿的规则。回到光环选择时保留原候选和刷新次数。

每次光环选择独立计算刷新次数。通常前 6 次刷新每次花费 1 金币，局外养成可将这个次数提高到 8 次。之后每次刷新花费 2 金币。一次刷新只更换一个候选。选定光环后回到首领备战，玩家再次点击开始战斗。

同一角色只有最后选定的光环效果生效。局面保留历次选定的光环及角色归属，先前光环带来的难度提升继续生效。

### 幕后茶歇

选完茶歇后可以直接领取原奖励关应掉落的晶矿和正常战斗奖励。按玩家观察，茶歇少发正常战斗结算时的 2 经验。

## 待核对

- 晶矿各品质的战利品和概率，以及不同节点和扑满对应的怪物掉落表。
- 其他血量变化的触发条件。
- 各羁绊提供的具体操作、目标、触发条件和选择模式。
