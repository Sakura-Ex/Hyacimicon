# Windows 玩家界面

[Hyacimicon](../../../apps/player/) 使用 Tauri 2、TypeScript 和 Lit。账号、对局和战斗在同一本书中切换。当前使用内存预览数据，重启后恢复初始状态。未接入的数据以短横线或空状态显示。

## 启动

在 Windows 安装 Node.js 22.12 及以上版本、npm、Rust MSVC 工具链、Visual Studio C++ Build Tools 和 WebView2。在仓库根目录运行：

```powershell
cd apps/player
npm ci
npm run tauri dev
```

`npm run dev` 在浏览器预览，`npm run build` 检查类型并构建页面，`npm run tauri build` 生成 Windows 程序和 NSIS 安装包。

书封、折口与纸层共用可缩放的矢量轮廓，侧边书签由 CSS 绘制。书册使用 1700 × 960 的逻辑画幅，根据可用宽高等比缩放，额外空间保持透明。两套 Noto SC 字体随应用分发，字体许可位于构建产物的 `licenses/`。头像、立绘、装备和花饰沿用[设计稿素材](../../../design-drafts/player-app/assets/README.md)。

### 装帧验收

修改书封、纸页或书签时，在调整前与最终截图验收时分别回看[初版战斗稿](../../../design-drafts/player-app/battle.png)及[装订素材](../../../design-drafts/player-app/assets/book/binding.png)。按同一画幅并排核对页宽、中缝位置、粉色页缘、页首花饰与书签外伸长度。检查三枚书签的根部伸入右页纸层，封板只在书签间隙露出。更换显示倍率后复查接缝及书外透明像素。

## 战斗模式

战斗书签首次进入常规战斗。右页可从独立目录选择一至四名角色和敌方单位，点“应用阵容”后，左页更新参战角色。也可用 `?page=battle` 直接进入。此入口只读取战斗目录与回放。

在战斗页点“货币战争”，或在对局页点“查看本局战斗”，即可使用当前账号的局面。该模式显示前后台、局内装备和本局羁绊。两种模式分别保留行动游标与查看对象；局面版本变化后重新读取本局回放，常规配置保留在本次会话中。

## 后端接入

在应用入口注入实现 `PlayerPort` 的适配器。账号、对局、战斗可分别实现 `AccountPort`、`MatchPort` 和 `BattlePort`。下表为预留的 Tauri 命令名。参数名、可空字段与返回结构以类型文件为准。适配器负责校验命令响应，失败时用包含具体原因的 Error 拒绝 Promise。

| 命令 | 输入 | 成功返回 |
| --- | --- | --- |
| `player_accounts` | 无 | 账号及各自的角色档案 |
| `player_import_account` | 文件名、JSON 原文 | 已导入账号 |
| `player_generate_account` | 32 位无符号整数种子 | 已生成账号 |
| `player_match` | 账号 ID | 当前可见局面及该版本的建议 |
| `player_set_shop_lock` | 对局 ID、预期版本、目标锁定状态 | 新版本的完整局面 |
| `player_save_feedback` | 对局 ID、预期版本、实际操作 ID、按字段键索引的实测整数 | 已核对并重新评估的完整局面 |
| `player_battle_catalogue` | 无 | 可选角色、敌人及默认常规配置 |
| `player_battle` | 常规配置或货币战争局面引用 | 阵容预览或按发生顺序排列的行动帧 |

写入时原子核对对局 ID 和版本。成功后返回新版本，重复或过期写入返回版本冲突。每个反馈字段定义名称、当前值与允许范围，各项建议可提供预填值。玩家可修改预填值；后端负责确定最终状态。缺少建议时返回空数组。预览模式可以记录玩家填写的金币和操作，账号导入与生成入口显示服务接入状态。

常规请求传入 `mode: standard`、`allyIds` 和 `enemyIds`。货币战争请求传入 `mode: currencyWars`、`matchId` 和 `revision`，后端据此解析阵容及专属规则。预览展示参战单位与装备，伤害、羁绊效果及行动顺序计算留待引擎接入。

`BattleResult.kind` 为 `preview` 时仅展示单位、编队及已知局面信息；为 `replay` 时提供行动帧与回放控制。

每个战斗帧携带行动者 ID、目标、伤害、截至该时刻的事件和单位快照。单位 ID 在帧内唯一，行动者引用本帧单位。图片路径引用随应用分发的资源。角色列表、行迹分组、库存、商店报价、建议、反馈字段和行动帧均按返回数组生成。

## 当前限制

| 场景 | 玩家现在能看到的结果 | 完整支持所需条件 |
| --- | --- | --- |
| 导入或生成账号 | 入口可选文件或填写种子，提交时显示服务接入提示 | 接入账号解析、生成及存储接口 |
| 查看数值、建议和回放 | 缺失数值显示短横线，建议和事件显示空状态；阵容预览支持切换查看对象 | 接入经过核对的账号数据、策略结果和战斗事件 |
| 保存实战记录 | 本次会话可更新金币与操作，关闭后清空 | 接入持久化及按新版本重新评估的服务 |
| 高倍率查看插画 | 书封和文字按显示倍率重绘，立绘、装备图和花饰的细节受原图分辨率限制 | 提供更高分辨率或矢量原稿 |
| 换设备查看 | 内嵌字体、固定画幅和等比缩放保持构图，窄窗口下文字随书页缩小 | 跨物理设备验收；WebView2 版本、字形抗锯齿与屏幕色彩仍会影响像素表现 |

本轮在一台 Windows 设备上运行正式版，通过 WebView2 分别验证了 100%、150%、200% 设备像素比。在每种设置下，对三枚书签各采样一条从右页内侧延伸到书签表面的水平线。九条采样线的 Alpha 均为 255，窗口右下方书外采样点的 Alpha 均为 0。
