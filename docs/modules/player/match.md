# 对局页

默认使用应用内演示服务，支持手动体验对局和观察演示模型。Windows 桌面版和浏览器开发预览共用页面流程。演示使用固定阵容样例与预设战斗结果。备战席满时，演示补给发放随组物品。

## 开局与恢复

1. 在「账号」选定账号，再打开「对局」书签。
2. 确认规则版本、敌人难度和负面词条数量。种子留空时自动生成，也可填写指定种子。
3. 点「开始新对局」，查看对手、各位面敌人与词条，选择投资环境后进入 `1-1`。
4. 本次应用会话中，各账号保留自己的活动对局。切回「对局」时重读快照并恢复推送。终局的「开启新对局」返回配置页。

页首显示当前位面进度与整局血量。第一位面有 9 格，第二和第三位面各有 7 格。进入下一位面时切换节点条。星形标记分别表示 `1-5`、`2-3`、`3-3` 的补给节点。悬停可查看节点类型和已正式进入的常规节点数。投资策略待选时，页首显示目标节点与「尚未入节点」。

## 常规备战

- 左页概览显示敌人、负面词条、投资环境、投资策略与各品质晶矿。展开晶矿后可开启当前可用的堆叠。备战席满时显示原因。
- 阵容保留前台 4 格、后台 9 格和备战席 9 格。拖动角色可移到合法空位，或与合法的已占用格互换。点角色可查装备、光环和可用的换位、出售操作，出售操作固定在详情顶栏，其余操作在独立列表内滚动。羁绊与羁绊机制分栏自适应页高并在各自区域内滚动，羁绊可浮层展开查看激活档位。
- 右页采用固定工作台布局，摘要、商店与本步建议不随整页滚动；装备与消耗品在各自托盘内独立滚动并隐藏滚动条。点击物品或拖到合法目标可执行装备、合成或消耗品操作。多个合法操作命中同一落点时，右页列出可选操作。
- 商店固定五格，已买报价留下空位。免费刷新次数、动作花费和利息上限随局面变化。右页可比较建议与备选，底栏「记录实际操作」可填写金币和整局血量。演示按本次会话保存实测记录，模拟局面继续按演示动作推进。

## 选择、战斗与结算

| 页面 | 操作 |
| --- | --- |
| 投资环境 | 从三项中选择，每格可刷新一次。 |
| 投资策略 | 同品质刷新，每格一次。确认后进入目标节点并发放入节点收益。 |
| 补给 | 从五组中领取一组，领取后前往下一节点。整组可刷新一次。 |
| 主角光环 | 在符合条件的首领备战页打开选择。点左页高亮角色可切换右页目标。刷新费用随次数变化。 |
| 羁绊选择 | 一次性选择确认后锁定。可更改选择先选待确认项，再应用。 |
| 幕后茶歇 | 选择结果后另行领取金币与晶矿，经验为 0。 |
| 战斗进行中 | 查看本局阵容，或重开、暂离。重开沿用本次尝试的随机序列。 |
| 战斗暂离 | 调整站位后重新进入，使用新的随机序列。 |
| 战斗暂不可用 | 查看错误，重试或暂离。本场尚未结算。 |
| 整局结束 | 查看通关或血量耗尽的结局、历次投资和光环。 |

投资策略、补给、主角光环均可返回备战后再继续选择，保留候选和刷新进度。返回备战时可以开晶矿，主角光环还可调整站位。羁绊操作在常规备战提供。战后展开结算条可查看血量、金币、连胜、经验与晶矿明细。

## 模型观战

点页首「交给模型」选择模型。右页 AI 操作流水显示动作和版本。需要继续手动操作时点「收回控制」。连接中断时用页首「重连」或底栏「重读局面」更新快照并恢复推送。

## 开发预览

从 `apps` 运行 `npm run dev`，打开 `/?page=match`。添加 `&scenario=<名称>` 可打开指定局面。

| 用途 | 场景 |
| --- | --- |
| 开局与备战 | `investmentEnvironment`、`preparation`、`full`（满阵容）、`stock`（长库存） |
| 待选 | `investmentStrategy`、`supply`、`spotlight`、`teaBreak`、`teaBreakReward` |
| 战斗与终局 | `battle`、`battleAway`、`battleUnavailable`、`finished`、`healthDepleted` |

用 `full` 在 1360 × 768 和 1560 × 900 检查概览、阵容、羁绊展开与商店。运行 `npm test` 检查会话、合法动作、订阅和传输。正式服务见[对局服务接入](match-commands.md)。
