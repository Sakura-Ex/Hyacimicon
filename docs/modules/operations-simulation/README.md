# 运营模拟

状态：首版已实现，支持网页手动操作。日期：2026-11-13。

本模块按 M3.2 的范围实现不含作战过程的整局运营环境。它负责商店、金币与经验、角色牌池和合成、投资环境、投资策略、难度词缀、节点推进和战斗结果结算。具体战斗由可替换的战斗进度提供器给出结果，本模块只处理战斗结束后的运营状态。

## 已实现

- 10 级商店费用概率，以及公开记录的五种角色费用和每种角色的牌池数量。
- 商店自动刷新、锁店、免费刷新、金币刷新、购买和出售。
- 等级经验表、购买经验、团队规模与三星角色合成。
- 20 节点模板，统计为 5 个奖励节点、9 个战斗节点、3 个遭遇节点和 3 个首领节点。
- 固定节点生成三个不重复投资策略，应用当前规则包支持的金币、经验、刷新、延迟收益、利息上限和强度效果。
- 开局投资环境和敌人词缀。支持指定词缀，或按难度随机生成。
- 五档自选难度和用于调试的抽象阵容强度估算。
- 玩家观测与商店隐藏牌池分离；相同种子和动作产生相同回放。
- 可注入的战斗进度接口。默认返回 100%，100% 判胜，低于 100% 判负。
- 本地网页操作与检查界面，支持手动执行运营动作并查看状态、事件和节点结果。

当前规则包内置 28 个代表性角色、15 个词缀、10 个投资环境、16 个投资策略和 5 档难度。完整角色、装备、全部 83 个投资环境和完整投资策略由数据快照导入后扩展，不在本仓库保存完整游戏数据。

## 运行

网页手动操作：

```powershell
uv run python -m examples.operations.web
```

启动后浏览器会打开 `http://127.0.0.1:8765/`。网页使用本地内存保存对局，关闭服务后不会保留会话。操作和检查说明见[网页操作与检查](web-interface.md)。

单局运行：

```powershell
uv run python -m examples.operations.simulate --difficulty standard --environment silver_age --seed 7
```

通过 `--battle-progress 0-100` 指定自动运行使用的战斗进度，默认 `100`。

批量评估：

```powershell
uv run python -m examples.operations.simulate --difficulty advanced --environment silver_age --seed 7 --runs 1000
```

验证：

```powershell
uv run python -m unittest discover -s tests -v
uv run ruff check .
uv run ruff format --check .
```

## 已知边界

本模块没有模拟角色技能、行动顺序、站位或伤害。抽象阵容强度只用于调试，不决定节点胜负；胜负由可替换的战斗进度提供器给出。

部分基础经济常量没有在公开 Wiki 中给出，当前使用规则包中的模拟假设值。每项来源、验证状态和待核对项见[数据来源与验证](data-provenance.md)。

设计说明见[运营模拟设计](design.md)。
