# 模块文档

先进入模块总览，查看用途、当前状态和阅读入口，再查阅具体设计。

| 模块 | 当前内容 |
| --- | --- |
| [账号与遗器数据](account-generation/README.md) | 账号金数与统一配装、推荐关联和资源分配，角色及遗器生成接口与共用数据流 |
| [基础战斗模拟](battle-simulation/README.md) | Rust `basic_v1` 显式面板与动作执行、单场事件与终止原因、种子重放及离线批次比较；不包含完整角色机制或整局扣血 |
| [单次战斗与整局推进](run-simulation/README.md) | 单次采样、AV诊断、显式资源结算、节点推进和训练转移；合成框架待团队认可 |

模块后续增加的设计、接口和验证文档由各自目录内的入口组织。
