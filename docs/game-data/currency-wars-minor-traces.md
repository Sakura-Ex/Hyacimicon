# 货币战争角色小行迹表

适用于 4.7 正式版货币战争 S2。每行对应一个角色，列名 `201` 至 `210` 为小行迹 ID，即完整节点 ID（`PointID`）的后三位。单元格为该节点激活后的加成，速度为固定值，其余加成以百分比表示。共收录 60 个角色，每个角色 10 个节点。

普通形态的完整节点 ID 由四位角色 ID 和三位小行迹 ID 拼接，例如希露瓦（`1103`）的 `201` 对应 `1103201`。强化形态（`EnhancedID = 1`）在最前面加 `1`，例如刃（`1205`）的 `201` 对应 `11205201`。星神★阿哈的三个玩法形态共用角色 `1511` 的行迹。帕姆大王（`6042`）是玩法专属角色，4.7 行迹配置中未找到对应节点。

角色名单按 `GridFightRoleBasicInfo.json` 的 S2 图鉴条目核对。加成取自 `AvatarSkillTreeConfig.json` 中一级 `Point09` 至 `Point18` 的 `StatusAddList`，并检查了 `AvatarSkillTreeConfigLD.json`。两份行迹配置均来自 [TurnBasedGameData](https://github.com/DimbreathBot/TurnBasedGameData) 的 4.7 正式版快照 `dfdfe3337bcfa14f000074d2dae7058118193ea6`。

600 条节点 ID 均与账号导入的[行迹绑定资料](../modules/account/reliquary-import.md#行迹依据与资料版本)一致。[试用表](character-trial-mapping.md#试用配置)所列的未激活小行迹均能匹配对应角色的属性和数值。
