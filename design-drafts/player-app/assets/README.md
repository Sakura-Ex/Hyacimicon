# 窗口原型素材

按当前参考图的实际引用整理。游戏美术归《崩坏：星穹铁道》相应权利人所有。文件名保留角色或物品 ID，便于和项目的数据条目关联。

| 目录 | 用途与来源 |
| --- | --- |
| [portraits](portraits/) | 风堇（1409）、景元（1204）两张彩色立绘，来自社区整理的 [StarRailRes](https://github.com/Mar-7th/StarRailRes)。原图保留透明背景，界面另加渐隐。 |
| [avatars](avatars/) | 17 张角色头像。草稿使用的 StarRailRes 头像副本按 `head-角色ID.png` 命名。 |
| [match-portraits](match-portraits/) | S2 图鉴快照中的 60 张角色图，用于对局阵容和商店。沿用数据仓库 `assets/encyclopedia/characters/` 下的角色 ID 和 WebP 原图，并随桌面版打包。 |
| [light-cones](light-cones/) 与 [relics](relics/) | 账号页展示的光锥与六件遗器，取自本轮图稿使用的游戏美术 PNG。 |
| [items](items/)、[traits](traits/)、[enemies](enemies/) | 局内装备和消耗品、羁绊与敌人。原文件来自同级数据仓库 `hsr-currency-wars-data/assets/encyclopedia/` 下的对应目录。 |
| [book](book/) | 草稿书页与装订背景 `binding.png`、页首花饰 `letterpress.png`。 |
| [ui](ui/) | 从草稿矢量绘图中导出的应用标识、模块书签和控件图标。单色 SVG 使用 `currentColor` 便于随界面换色。 |

桌面版随应用打包 `traits/` 下的图标。文件与 S2 数据快照 `encyclopedia-4.6.54-679438c4be1c` 中 `presentation.json` 的羁绊图标路径对应。
