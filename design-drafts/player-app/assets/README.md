# 窗口原型素材

本目录仅保留项目自绘与排版用的界面资源，不保存游戏美术原图。

| 目录 | 用途与来源 |
| --- | --- |
| [book](book/) | 草稿书页与装订参考图 `binding.png`，以及随桌面版打包的页首花饰 `letterpress.png`。 |
| [ui](ui/) | 从草稿矢量绘图中导出的应用标识、模块书签和控件图标，随桌面版打包。单色 SVG 使用 `currentColor` 便于随界面换色。 |

角色头像、角色立绘、光锥、遗器以及货币战争的对局角色图、羁绊图标、局内装备、消耗品与敌人图像均由 Windows 桌面版在安装并启动后按校验清单自动下载至本地缓存（详见 [Windows 玩家界面文档](../../../docs/modules/player/README.md#游戏图像)）。
